# Spectralverse benchmark programme

The packaged schema and `hm_benchmark_protocol()` admit metadata only; they do
not download, redistribute or execute data. HeiPor is the primary anatomy
cohort. xeno is separate species/perfusion development. ManU requires admitted
human-use terms and verified person grouping. Burn/TSCI are not admitted here.

Every execution must retain dataset/reference release identities, identical
source cases and ROIs, native/adapted/auxiliary input track, context budget,
pretraining overlap, prior outcome access, target access and a per-model,
per-task, per-platform qualification/evidence lane. Unknown overlap cannot
support an untouched-target claim. Unqualified SDK/checkpoint/platform lanes
remain blocked. Instrument parity additionally needs real instrument exports,
reader/calibration versions, band geometry and numerical tolerances fixed
before readback. No instrument or scientific result is supplied by this contract.

Small synthetic tests in `tests/testthat/test-benchmark-protocol.R` independently
exercise metadata admission and matched-support rejection. Large public data,
raw human data and private clinical cohorts are deliberately absent.
